## 关键技术决策

- **状态变量命名**：复用 codex 的 `currentCommentSort / currentCommentTag / currentParagraphIdx`，不引入冗余 `commentState` 包裹（计划里写的复杂 commentState 未落地，因为现有命名够清晰且不影响功能）。
- **未匹配块**：CSV targetId=190/191 没有对应段落（`paras[190]` undefined），按 PRD §14.3 渲染为 `.cm-unmatched-module`，"查看本段 N 条评论"按钮 disabled（这些评论对象本身无段落锚点，hover/click 行为被显式禁用）。
- **字段适配**：现有旧字段读取（`c.user / c.content / c.likes / c.time / c.level / r.replyTo`）全部替换为 WIP 已有的 `commentUser / commentBodyHtml / commentLikes / commentTime` 适配函数，正文必须 escapeHtml。CSV 缺少的 userBadge/真实头像/IP 按 PRD §6 兜底策略隐藏或用 userGuid 哈希色 + 首字母替代。
- **楼中楼默认收起**：PRD §2 目标 5 + §9-6 要求"默认收起回复，按需展开"，我把 `.cm-sub` 的 display 默认设为 none，sub-toggle 按钮动态展开/收起全部。
- **build_comment_data.py bug**：re.subn(block, content) 把 block 当 replacement 字符串，`\\` 被解释成 `\` 导致写入的数据被去转义污染。改为 `pattern.subn(lambda _m: block, content)` —— 这是 codex WIP 里漏的，发现时 index.html 的所有 `\\n` 已被写成 `\n`（变成换行符）。修复后重烤一次。
- **pre-commit hook**：因为每个 commit hook 都会跑一次完整测试（~20s），目前可接受；如果以后测试变慢可加分层（先跑 A 数据段、再跑 B 浏览器段）或加到 CI。
